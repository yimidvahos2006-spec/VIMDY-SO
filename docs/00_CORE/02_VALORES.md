# 02_VALORES.md

## 1. Simplicidad Radical
Si un proceso requiere más de dos clics o una explicación compleja para el usuario final, no está terminado. Diseñamos para la velocidad y la intuición en entornos de alta presión.

## 2. Precisión Operativa
En gastronomía, cada segundo e insumo cuentan. Garantizamos datos exactos en inventarios, cajas y comandas; no hay margen para la ambigüedad.

## 3. Fiabilidad Inquebrantable
El sistema debe responder sin fallas en las horas pico. Un sistema caído es un servicio paralizado; la estabilidad es nuestra prioridad técnica absoluta.

## 4. Agilidad Adaptativa
Evolucionamos al ritmo que exige la industria gastronómica, respondiendo a problemas reales del sector con soluciones funcionales inmediatas.
