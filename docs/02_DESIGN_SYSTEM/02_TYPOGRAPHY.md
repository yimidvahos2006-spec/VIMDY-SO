# VIMDY DESIGN SYSTEM
# 02 — TYPOGRAPHY

---

# Objetivo

La tipografía es la voz visual de VIMDY.

Debe transmitir:

• Orden

• Claridad

• Precisión

• Profesionalismo

Nunca protagonismo.

---

# Filosofía

El usuario no debe notar la tipografía.

Debe notar únicamente la información.

La tipografía desaparece para dejar hablar al negocio.

---

# Fuente Oficial

Inter

Fallback:

System UI

Segoe UI

Roboto

Helvetica

Arial

Sans-serif

Nunca utilizar fuentes decorativas.

Nunca utilizar fuentes condensadas.

Nunca utilizar fuentes manuscritas.

---

# Longitud

Las líneas largas cansan.

Máximo recomendado:

80 caracteres por línea.

---

# Alineación

Todo el sistema utiliza alineación izquierda.

Nunca justificar texto.

Nunca centrar párrafos.

Solo se centra:

Logos

Pantallas vacías

Mensajes de bienvenida

---

# Mayúsculas

Solo para:

Etiquetas

Estados

Categorías

Nunca escribir párrafos completos en mayúsculas.

---

# Negrita

La negrita es un recurso limitado.

Solo se utiliza para:

Números

Totales

Información importante

Nunca para decorar.

---

# Cursiva

Prohibida.

---

# Subrayado

Solo para enlaces.

Nunca como decoración.

---

# Legibilidad

Toda tipografía debe cumplir:

Contraste AA o superior.

Lectura cómoda durante jornadas de 12 horas.

---

# Regla Suprema

La tipografía existe para que el usuario piense en su negocio.

Nunca para que piense en el diseño.
