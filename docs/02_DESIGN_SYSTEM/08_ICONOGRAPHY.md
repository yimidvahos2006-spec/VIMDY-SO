# VIMDY DESIGN SYSTEM
# 08 — ICONOGRAPHY

---

# Objetivo

La iconografía de VIMDY existe para facilitar la comprensión inmediata de la interfaz.

Los iconos nunca son decoración.

Siempre apoyan la información.

Nunca la reemplazan.

---

# Filosofía

Un buen icono debe responder una pregunta en menos de un segundo.

Si el usuario necesita pensar qué significa, el icono debe cambiar.

---

# Principio Fundamental

Primero el texto.

Después el icono.

Nunca al revés.

Los iconos ayudan.

El texto comunica.

---

# Librería Oficial

Toda la aplicación utiliza únicamente:

Lucide Icons

No mezclar librerías.

No mezclar estilos.

# Checklist

Antes de aprobar un icono verificar:

□ Pertenece a Lucide.

□ Tiene tamaño oficial.

□ Utiliza color oficial.

□ Está alineado.

□ Tiene significado.

□ No es decorativo.

□ Mantiene consistencia.

---

# Regla Suprema

Si al eliminar un icono el usuario sigue entendiendo perfectamente la interfaz,

ese icono probablemente nunca fue necesario.
