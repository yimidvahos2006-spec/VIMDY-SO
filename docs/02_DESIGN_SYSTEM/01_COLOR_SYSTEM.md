# VIMDY DESIGN SYSTEM
# 01 — COLOR SYSTEM

---

# Objetivo

El color en VIMDY no existe para decorar.

Existe únicamente para comunicar información.

Todo color debe tener un significado.

Si un color no transmite información, se elimina.

---

# Filosofía

Mientras menos colores tenga una pantalla,
más rápido trabaja el cerebro.

La ausencia de color también comunica.

El negro es información.

El espacio también es información.

---

# Paleta Oficial

## VOID

#09090B

Es el color principal.

Representa silencio.

Representa estabilidad.

Representa profundidad.

Toda la aplicación nace desde aquí.

Nunca cambia.

---

## SURFACE

#121215

Representa superficies.

Sidebar.

Header.

Drawer.

Paneles.

Nunca debe llamar la atención.

---

## CARD

#18181C

Representa elementos interactivos.

Cards.

Inputs.

Tablas.

Filas.

Listas.

No debe competir con el contenido.

---

## BORDER

#27272A

Representa estructura.

Nunca decoración.

Su única misión es separar elementos.

---

## TEXT PRIMARY

#FFFFFF

Texto principal.

KPIs.

Números.

Títulos.

Botones primarios.

---

## TEXT SECONDARY

#A1A1AA

Texto descriptivo.

Subtítulos.

Información secundaria.

---

## TEXT MUTED

#71717A

Labels.

Placeholders.

Texto deshabilitado.

Información poco importante.

---

# Color de Marca

## VIMDY BLUE

#38BDF8

Es el único color protagonista.

Solo aparece cuando el sistema necesita dirigir la atención del usuario.

Se utiliza exclusivamente para:

• Acción principal

• Estado activo

• IA

• Selección

• Focus

• Elemento actualmente utilizado

Nunca se utiliza como decoración.

---

# Colores de Estado

## SUCCESS

#22C55E

Indica que una operación terminó correctamente.

Ejemplos:

Venta registrada.

Pedido enviado.

Producto guardado.

---

## WARNING

#F59E0B

Indica atención.

No representa error.

Ejemplos:

Inventario bajo.

Caja próxima al cierre.

Producto por agotarse.

---

## ERROR

#EF4444

Representa problemas reales.

Nunca advertencias.

Ejemplos:

No se pudo cobrar.

Error crítico.

Sin conexión.

---

## INFO

#38BDF8

Información.

Sugerencias de IA.

Recomendaciones.

Mensajes informativos.

---

# Regla del Azul

Si existen más de tres elementos azules visibles simultáneamente en una pantalla, el diseño debe revisarse.

El azul pierde importancia cuando aparece demasiado.

---

# Regla del Rojo

El rojo nunca se utiliza para decoración.

Solo indica riesgo.

Pérdida.

Bloqueo.

Error.

Nunca otra cosa.

---

# Regla del Verde

El verde solo aparece cuando una acción terminó correctamente.

Nunca antes.

Nunca durante.

---

# Regla del Amarillo

El amarillo representa atención.

No peligro.

No error.

---

# Contraste

Todo texto debe cumplir niveles AA o AAA.

La legibilidad siempre tiene prioridad sobre la estética.

---

# Oscuridad

VIMDY nace oscuro.

No es una moda.

Reduce fatiga visual.

Mejora concentración.

Hace resaltar la información.

---

# Regla Suprema

El color nunca debe ser el protagonista.

La información sí.
