# VIMDY DESIGN SYSTEM
# 03 — SPACING

---

# Objetivo

El espacio es uno de los componentes más importantes de VIMDY.

No representa vacío.

Representa claridad.

Representa orden.

Representa velocidad.

Representa lujo.

Mientras menos tenga que trabajar el ojo del usuario para separar la información, más rápido podrá trabajar.

El espacio reduce la carga cognitiva.

---

# Filosofía

Un software barato intenta llenar toda la pantalla.

Un software premium deja respirar la información.

En VIMDY el espacio es infraestructura.

Nunca decoración.

Nunca desperdicio.

---

# La Regla del Aire

Todo elemento importante debe tener suficiente espacio alrededor para ser entendido inmediatamente.

Si dos componentes parecen pegados, el diseño está fallando.

---

# La Regla del Silencio

El espacio también comunica.

Una pantalla con buen espacio transmite:

• Control

• Calma

• Precisión

• Profesionalismo

Una pantalla saturada transmite:

• Estrés

• Caos

• Baja calidad

---

---

# Espacio Mínimo

Nunca colocar dos componentes separados por menos de 8 px.

---

# Espacio Máximo

Nunca crear huecos gigantes que rompan el ritmo visual.

Todo debe sentirse continuo.

---

# Ritmo Vertical

Toda pantalla debe seguir un ritmo constante.

No pueden existir bloques completamente pegados y luego enormes espacios vacíos.

El usuario debe sentir continuidad.

---

# Ritmo Horizontal

Todos los componentes importantes deben alinearse.

La alineación transmite orden.

---

# La Regla del Escaneo

El ojo humano debe recorrer la pantalla naturalmente.

De izquierda a derecha.

De arriba hacia abajo.

El espacio guía la mirada.

---

# Espacio y Jerarquía

Mientras más importante sea un elemento:

Más espacio alrededor tendrá.

No necesita hacerse más grande.

El espacio comunica importancia.

---

# Espacio Negativo

No llenar espacios por miedo.

El vacío bien utilizado transmite lujo.

---

# Errores Prohibidos

❌ Componentes pegados.

❌ Márgenes diferentes en la misma pantalla.

❌ Padding diferente entre tarjetas iguales.

❌ Formularios comprimidos.

❌ Tablas sin respiración.

❌ Sidebar saturado.

❌ Header lleno de elementos.

---

# Checklist

Antes de aprobar una pantalla verificar:

□ ¿Respira?

□ ¿Los elementos importantes tienen aire?

□ ¿Se entiende la jerarquía?

□ ¿Todo mantiene el mismo ritmo?

□ ¿Existe equilibrio visual?

□ ¿Hay espacio suficiente para trabajar durante horas?

---

# Regla Suprema

El espacio no es ausencia de diseño.

El espacio ES diseño.

Si una pantalla se siente apretada,

VIMDY está fallando.
