# NAVIGATION SYSTEM

## Objetivo

La navegación conecta todas las aplicaciones de VIMDY.

Nunca debe sentirse como un menú.

Debe sentirse como moverse naturalmente dentro del negocio.

El usuario no "entra" y "sale" de módulos.

Simplemente continúa trabajando.

---

# Filosofía

La navegación debe ser invisible.

Mientras menos piense el usuario dónde hacer clic,

mejor está diseñada.

---

# Principios

La navegación siempre debe ser:

• Clara

• Consistente

• Silenciosa

• Predecible

• Instantánea

Nunca sorprende.

Nunca cambia de lugar.

Nunca obliga al usuario a aprender de nuevo.

---

# Estructura

VIMDY tiene únicamente dos niveles.

Nivel 1

Aplicaciones principales.

Nivel 2

Herramientas internas.

Nunca existe un tercer nivel.

---

# Aplicaciones Principales

Centro de Mando

Venta

Operación

Productos

Clientes

Asistente IA

Configuración

Estas aplicaciones son permanentes.

Nunca cambian de posición.

---

# Sidebar

El Sidebar es una extensión del fondo.

No parece una caja.

No parece un panel.

No roba atención.

---

Nunca cambia de color.

# Header

El Header permanece fijo.

Siempre visible.

Contiene únicamente:

Buscador global

Notificaciones

Perfil

Nada más.

---

# Buscador Global

Siempre disponible.

Atajo

Ctrl + K

Desktop

⌘ + K

Mac

Debe encontrar:

Productos

Clientes

Ventas

Facturas

Configuraciones

Mesas

Pedidos

Todo desde un único lugar.

---

# Breadcrumb

No existen Breadcrumbs.

La estructura es suficientemente simple.

---

# Navegación entre pantallas

Debe sentirse inmediata.

Sin pantallas blancas.

Sin cargas visibles.

Sin saltos.

---

# Cambio de Aplicación

Al cambiar entre aplicaciones:

Se mantiene el contexto.

El usuario nunca siente que abandonó el sistema.

Solo cambió de herramienta.

---

# Scroll

Cada aplicación controla su propio scroll.

El Header nunca desaparece.

El Sidebar nunca desaparece.

---

# Mobile

El Sidebar desaparece.

Se reemplaza por:

Bottom Navigation

Máximo

5 botones.

Más opciones

Menú adicional.

---

# Navegación por teclado

Toda la aplicación debe poder usarse con teclado.

TAB

SHIFT + TAB

ENTER

ESC

Flechas

Ctrl + K

Siempre disponibles.

---

# Accesibilidad

Toda navegación debe tener:

aria-label

Focus visible

Orden lógico

Compatibilidad con lectores de pantalla

---

# Rendimiento

La navegación nunca recarga toda la aplicación.

Solo cambia el contenido.

Debe sentirse como una aplicación nativa.

---

# Reglas

Nunca más de una navegación principal.

Nunca menús infinitos.

Nunca submenús de submenús.

Nunca mover elementos entre versiones.

La memoria del usuario es sagrada.

---

# Regla Suprema

El usuario nunca debe preguntarse:

"¿Dónde estaba esa opción?"

Si necesita buscar un menú,

la navegación está mal diseñada.
