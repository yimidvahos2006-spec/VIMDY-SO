# 09_CONFIGURACION.md

# Aplicación Configuración

---

# Definición

Configuración es la aplicación encargada de administrar el funcionamiento interno de VIMDY.

Aquí se define cómo opera el sistema.

No participa en la operación diaria del negocio.

Solo modifica su comportamiento.

---

# Objetivo

Centralizar toda la configuración del negocio en un único lugar seguro, organizado y fácil de administrar.

Toda modificación realizada aquí afecta el funcionamiento del sistema completo.

---

# Usuario Principal

* Propietario
* Administrador
* Supervisor autorizado

---

# Funciones Principales

## Empresa

Permite configurar:

* Nombre comercial.
* Razón social.
* NIT.
* Dirección.
* Ciudad.
* Teléfono.
* Correo.
* Logo.
* Moneda.
* Zona horaria.

---

## Sucursales

Permite administrar:

* Crear sucursal.
* Editar sucursal.
* Activar o desactivar.
* Configurar cajas.
* Configurar inventarios independientes.

---

## Usuarios

Permite:

* Crear usuarios.
* Editar usuarios.
* Desactivar usuarios.
* Restablecer contraseña.
* Asignar permisos.

---

## Roles

Ejemplos:

* Administrador.
* Gerente.
* Cajero.
* Mesero.
* Cocina.
* Barra.
* Inventario.

Cada rol determina exactamente qué puede hacer el usuario.

---

## Permisos

Cada permiso podrá activarse o desactivarse.

Ejemplos:

* Cobrar.
* Anular ventas.
* Aplicar descuentos.
* Editar productos.
* Ajustar inventario.
* Ver reportes.
* Configurar empresa.
* Administrar usuarios.

---

## Impresoras

Configuración de:

* Cocina.
* Barra.
* Caja.
* Facturación.

Cada estación puede utilizar impresoras diferentes.

---

## Facturación

Configuración de:

* Numeraciones.
* Resoluciones.
* Impuestos.
* Facturación electrónica.
* Prefijos.
* Series.

---

## Integraciones

Permite conectar:

* Pasarelas de pago.
* Facturación electrónica.
* WhatsApp.
* Correo.
* APIs.
* Servicios externos.

---

## Preferencias

Configuraciones generales.

Ejemplos:

* Idioma.
* Formato de fecha.
* Formato de hora.
* Tema.
* Sonidos.
* Notificaciones.
* Copias automáticas.

---

# Seguridad

Toda acción importante queda registrada.

Ejemplos:

* Cambio de contraseña.
* Cambio de permisos.
* Eliminación de usuario.
* Cambio de impuestos.
* Cambio de configuración.

Todo queda auditado.

---

# Historial

Configuración conserva:

* Usuario.
* Acción realizada.
* Fecha.
* Hora.
* Equipo.
* Dirección IP (si aplica).

Nunca existirán cambios invisibles.

---

# Respaldo

Permite:

* Crear respaldos.
* Restaurar respaldos.
* Programar respaldos automáticos.
* Consultar historial.

---

# Estados Vacíos

Ejemplos:

"No hay usuarios registrados."

"No existen sucursales."

"No hay impresoras configuradas."

Nunca habrá pantallas vacías.

---

# Qué Nunca Hará

Configuración nunca:

* Registrará ventas.
* Administrará pedidos.
* Gestionará mesas.
* Modificará comandas.

Su responsabilidad es definir cómo funciona VIMDY.

No operar el negocio.

---

# Relación con otras Aplicaciones

Configuración afecta directamente:

* Centro de Mando.
* Venta.
* Operación.
* Productos.
* Clientes.
* Asistente IA.

Toda modificación se aplica automáticamente según los permisos correspondientes.

---

# Regla Suprema

Ninguna configuración crítica podrá modificarse accidentalmente.

Toda acción importante debe ser clara, segura y completamente trazable.

Configurar VIMDY debe sentirse tan confiable como configurar un sistema operativo profesional.
